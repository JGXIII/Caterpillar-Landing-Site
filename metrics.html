What is and isn't collected

Events are keyed to a random UUID generated once per install. It is not the Caterpillar account, the Apple ID, or the device id — deleting the app ends that identity permanently, and nothing here can be traced back to a person.

Never collected: search queries, food names, weights, photos, emails, or anything else typed or captured. Event properties carry only small fixed values — which scan route, which paywall reason — and the server clamps them again on arrival. Rows older than 180 days are deleted.

Testers can switch this off in the app; off means nothing is queued or sent. The table has row-level security with no policies, so the key shipped in the app can neither read nor write it — this page reads aggregates through a server function that never returns a single row.
